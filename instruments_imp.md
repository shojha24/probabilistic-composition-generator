⚠️ Common Pitfalls to Avoid in JFugue
Spacing Inside Brackets: JFugue parses string constants explicitly . Ensure you do not add trailing spaces inside the brackets (e.g., use I[Acoustic_Grand_Piano] and never I[Acoustic_Grand_Piano ]) .
Alternative Constant Formats: JFugue supports abbreviated names (e.g. I[Rhodes_Piano] or I[Rhodes]), but sticking to the fully defined string constant ensures universal portability across different version platforms .

To understand how these instruments behave in JFugue, we have to look under the hood at how JFugue interacts with your computer's native software synthesizer (MIDI engine).
The short answer is: Yes, a plucked instrument can physically "sustain" in JFugue, but its volume envelope will rapidly decay to silence anyway.
Here is exactly how this works and how you can manipulate it.

🎛️ How JFugue Handles Instruments
When you write a line of code like this in JFugue:
Pattern pattern = new Pattern("I[Acoustic_Guitar_Steel] Cq Dq Eq Fq");

JFugue doesn't generate raw audio. Instead, it sends standard MIDI Note On and Note Off messages to the Java Sound Synthesizer:
When a note starts, it sends Note On along with the Instrument Change (Program Change) message.
When the duration is over (e.g., a quarter note q), it sends Note Off.

🏹 The Physics of Plucked vs. Sustained Instruments in MIDI
The synthesizer’s output depends entirely on the ADSR Envelope (Attack, Decay, Sustain, Release) designed into that specific instrument patch.
Vol ▲      Plucked Instrument (Guitar)         Sustained Instrument (Organ/Pad)
    │        /\                                    /───────────────\
    │       /  \                                  /                 \
    │      /    \                                /                   \
    │     /      \______                        /                     \
    │    /              \______                /                       \
    └───/──────────────────────\─────►        /─────────────────────────\───►
       Note On             Note Off         Note On                  Note Off

Case 1: Plucked Instruments (Guitar, Sitar, Harpsichord, Banjo/Balalaika, Marimba)
How they behave: When you send a Note On message, the synthesizer triggers a sample of a physical string being plucked or a bar being struck.
What happens if you hold it? If you program a whole note (w) or tie notes together to create a long "sustained" sound, JFugue will keep the key held down. However, the physical model of the instrument has no continuous vibration source. The sound wave will naturally decay to total silence in 1 to 2 seconds, regardless of how long you hold the note.
Pedal Simulation: If you try to use a MIDI sustain pedal (Control Change 64) with a Harpsichord or Xylophone, it will only let the natural string/bar vibration ring out to its physical limit. It will not hold the sound indefinitely.
Case 2: Sustained Instruments (Organs, Synths, Bowed Strings, Winds, Brass)
How they behave: These instruments have a continuous energy source (blowing air, a moving bow, or an oscillator circuit).
What happens if you hold it? As long as JFugue does not send a Note Off message, the sound will play forever at maximum volume.
Mix Warning: Because of this, failing to specify tight note durations on these instruments will lead to massive muddy overlapping frequencies in your arrangements.

🛠️ How to "Fake" Sustained Sounds on Plucked Instruments
If your AAM model requires a Plucked Instrument (like a Sitar or Balalaika) to play a long "Pad" role, you cannot simply hold a single long note. Instead, you have to use classic musical workarounds:
The Tremolo / Roll (Recommended for JFugue):
Rapidly re-trigger the note using very fast durations (e.g., thirty-second notes t). This mimics a mandolin or balalaika player rapidly plucking back and forth to keep the string vibrating.
// Fakes a sustained C chord on a Balalaika using rapid strumming
Pattern balalaikaPad = new Pattern("I[Banjo] Ct Ct Ct Ct"); 


Arpeggiation:
Break a sustained block chord into a cascading loop. While the first note decay begins, the second and third notes trigger, keeping the harmonic space continuously filled.
Reverb & Delay (External):
If you are rendering your JFugue MIDI using an external Digital Audio Workstation (DAW) or a custom soundfont, you can apply heavy artificial reverb to catch the decay tail of the plucked instruments and wash it out into a continuous pad.

📌 Summary Rule of Thumb
If your MIDI channel has a Sustained instrument, Note Off (duration) is king.
If your MIDI channel has a Plucked instrument, Note On (re-triggering) is king.

💡 JFugue Tip: Using numbers directly
In JFugue, you don't actually need to use the full name string in the I[...] tags if you don't want to. You can call instruments directly by their 1-based index like this:
// Equivalent ways to play on a Sitar
Pattern playSitarString = new Pattern("I105 Cq Dq Eq"); 
Pattern playSitarDirect = new Pattern("I[Sitar] Cq Dq Eq");
